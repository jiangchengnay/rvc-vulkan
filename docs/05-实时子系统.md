## 3. 废弃原因（4 因）

1. **补丁堆叠**：20+ 轮修复从未重新设计。
2. **验证方法不可信**：结构指标（频谱平坦度/SOLA 连续性/mel 距离）无法区分"正确输出"与
   "固定噪声"——只要噪声平稳、谱形平坦且能量低，指标全 PASS 但听感仍是噪声。
3. **根因**：输出重采样使用 np.interp，无抗混叠。
4. **范式缺陷**：f0 整窗重算、无 SOLA、return_length 无余量。

## 4. 重写依据（后续工作）

- 块长建议 **1.0s**（160 倍数硬约束）；性能目标 1.0s 块推理 <1.0s。
- f0：整窗 + 尾部帧优先；增量缓存可选。
- SOLA：40ms 缓冲 + 10ms 搜索 + sin² 窗。
- **验收必须包含听感复核**（结构指标不可单独作结论）；测试须设固定 seed、真人真声、对照组。

## 5. 核心教训（防重蹈）

1. 重采样必须带抗混叠。
2. 验证必须设 seed + 真人真声 + 对照组 + 听感复核。
3. 块边界 / 缓存失效是设计问题而非参数问题——改动需从设计层出发。
4. 不确定的修复链优先"重设计"而非"再打补丁"。
